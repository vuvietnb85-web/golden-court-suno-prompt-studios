# Golden Court (Sân Vàng) - Suno AI Prompt Studio Directory

A free PWA that lists 9 Suno AI music prompt studios and scores each one publicly on 8 criteria: duration lock, character budget, on-device measurement, tempo and key, named sound quality, lyrics policy, Suno paste flow, and single clear purpose.

Live app: https://web-pwa-prompt-auto-sunoai-vxo.grok.me

## Features
- Search, sort and filter studios (with lyrics, instrumental, EDM, live and folk)
- Score sheets explaining every rating
- Side-by-side comparison table with copy button
- Vietnamese and English interface

Built with Grok by VXO Digital Lab. Not affiliated with Suno.

Note: this repository contains the production build of the site.
